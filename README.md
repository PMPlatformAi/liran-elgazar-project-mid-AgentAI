# מערכת ניהול הזמנות ולידים - hotelAi

מערכת לניהול הזמנות חדרים במלון גנרי, כולל ניהול אורחים, לידים וחשבוניות.
נבנתה כפרויקט אמצע קורס בפייתון, ובהמשך תחובר לסוכן AI בפרויקט hotelAi.

## מה מומש

- ניהול תורים (הזמנות): הוספה, צפייה, עדכון סטטוס, מחיקה
- מניעת התנגשויות: לא ניתן להזמין את אותו חדר בטווח תאריכים חופף
- **בונוס 1**: ניהול לקוחות (guests) וחשבוניות מס (invoices), כולל קישור בין הזמנה ללקוח וצפייה בהיסטוריה
- **בונוס 2**: ניהול לידים (leads), כולל המרת ליד ללקוח קיים

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `schema.sql` | הגדרת כל טבלאות בסיס הנתונים |
| `models.py` | מחלקות OOP: Guest, Room, Reservation, Lead, Invoice |
| `database.py` | כל פעולות ה-CRUD מול בסיס הנתונים (SQLite) |
| `mock_data.py` | הכנסת נתוני דמה ראשוניים לבדיקה |
| `main.py` | תפריט הרצה ראשי מהטרמינל |
| `hotel.db` | בסיס הנתונים - **נוצר אוטומטית בהרצה, לא מוגש** |

## איך להתקין ולהריץ

1. ודאו שמותקן Python 3 (אין צורך בספריות חיצוניות - `sqlite3` מובנה בפייתון).
2. פתחו טרמינל בתיקיית הפרויקט.
3. הריצו פעם אחת בלבד כדי ליצור את בסיס הנתונים ולהכניס נתוני דמה:

   ```bash
   python mock_data.py
   ```

   פעולה זו תיצור את הקובץ `hotel.db` ותכניס אליו אורחים, חדרים, הזמנות, לידים וחשבוניות לדוגמה.

4. הריצו את המערכת:

   ```bash
   python main.py
   ```

5. פתיחת בסיס הנתונים לצפייה ידנית (אופציונלי): אפשר לפתוח את `hotel.db` בכל תוכנת SQLite (למשל DB Browser for SQLite) כדי לראות את הטבלאות בצורה גרפית.

## הערה חשובה

אם תרצו לאפס את המערכת (למחוק את כל הנתונים ולהתחיל מחדש) - פשוט מחקו את הקובץ `hotel.db` והריצו שוב `python mock_data.py`.
